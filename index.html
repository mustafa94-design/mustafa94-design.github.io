Refrigerant workbench

Refrigerant workbench

1. Superheat, subcooling and pressure ratio

Saturation values are computed from real-fluid property data (CoolProp). Superheat uses the dew point, subcooling uses the bubble point, so it is correct for blends with glide such as R-454B. Example readings shown.

Gauge pressure uses 14.7 psi atmospheric. Measure superheat at the compressor end of the suction line and subcooling at the condenser outlet, at steady state. Inverter and EEV systems are usually charged by weight and controller data, not by these numbers. Always use the manufacturer's target values.

2. Liquid line lift and flash-gas margin

Static head is density × g × height, using liquid density at 40 °C. Friction loss must come from the manufacturer's data.

3. Extra refrigerant for long line sets

The rate is an example. It depends on the liquid line diameter and the refrigerant, so use the value in the installation manual. Some manufacturers require no removal for shorter lines and others do; follow the manual.
